# agent-sessions v0.1.0

This is the first public release of `agent-sessions`, a local search tool for coding-agent sessions.

## Highlights

- Search Pi, Codex, OpenCode, and Claude Code sessions from one CLI.
- Find exact text with SQLite FTS5 and BM25.
- Find misspelled text with character n-grams.
- Find related text with local Ollama embeddings.
- Combine all search channels into one ranked result per session.
- Filter results by harness, project path, role, and date.
- Print native resume commands without running them.
- Update the index without parsing unchanged sources again.
- Preserve embeddings for unchanged text chunks.
- Produce JSON output for scripts and integrations.

## Installation

Install the default embedding model:

```sh
ollama pull all-minilm
```

Install `agent-sessions`:

```sh
go install github.com/Thelost77/agent-sessions/cmd/agent-sessions@v0.1.0
```

## Requirements

- Go 1.25 or later
- Ollama for semantic indexing and search

Lexical and fuzzy search work without Ollama.

## Privacy

All search data stays on the local machine. The tool accepts only loopback Ollama URLs.
