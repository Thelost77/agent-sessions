# agent-sessions v0.1.1

This release reduces low-relevance search results and uses a smaller default result set.

## Changes

- Changed the default result limit from ten to three.
- Added a default semantic cosine similarity threshold of `0.60` for `all-minilm`.
- Removed semantic candidates below the threshold before reciprocal rank fusion.
- Added `--semantic-threshold` for query-specific threshold changes.
- Added `embedding.threshold` to the configuration file.
- Added semantic similarity values to JSON output.
- Added semantic similarity values to `--explain` output.
- Rejected threshold values outside the range from `0` to `1`.

The `--limit` option still sets only the maximum result count. Lexical and fuzzy channels can return results without semantic evidence.

## Installation

Install or update `agent-sessions`:

```sh
go install github.com/Thelost77/agent-sessions/cmd/agent-sessions@v0.1.1
```

Semantic search requires Ollama and the default embedding model:

```sh
ollama pull all-minilm
```
