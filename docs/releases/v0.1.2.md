# agent-sessions v0.1.2

This patch release fixes lexical-only search.

## Changes

- Fixed a nil-pointer panic when `search --lexical-only` disabled semantic search.
- Added a regression test for lexical-only CLI searches.

## Installation

Install or update `agent-sessions`:

```sh
go install github.com/Thelost77/agent-sessions/cmd/agent-sessions@v0.1.2
```
